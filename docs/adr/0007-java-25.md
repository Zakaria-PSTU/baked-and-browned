# ADR-0007: Java 25 runtime

- Status: Accepted
- Date: 2026-11-16

## Context
`CLAUDE.md` and `architecture.md` specified Java 25; the initial planning request mentioned Java 21. Both are LTS releases supported by Spring Boot 4.x.

## Decision
Use Java 25 for the backend: compiler release level, Maven toolchain, CI runner and the runtime container base image.

## Consequences
- All build files, CI workflows and Dockerfiles pin Java 25; no Java 21 compatibility is maintained.
- Exact compatible versions of Spring Boot 4.x, Hibernate, Flyway and Testcontainers are confirmed and recorded during Phase 1 bootstrap.
- Language features available in Java 25 may be used, but only where the team's tooling (IDE, static analysis) supports them.
